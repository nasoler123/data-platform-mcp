Keep source provenance, commit identifiers and documented redactions. Do not present archived excerpts as complete runnable modules or local checks as production acceptance.

Do not add credentials, identifiable client material, deployment configuration or a production integration. Do not alter the private source repositories to maintain this portfolio.

Use a feature branch and pull request; merge with squash. Run the local verification command. No GitHub Actions are required for this repository.
