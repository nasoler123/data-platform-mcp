# Perfil genérico de la copia inicial gratuita: Shopify, Google Ads, Meta Ads,
# TikTok Ads y Amazon Ads.
#
# No es el expediente de un cliente: es la configuración habitual de un ecommerce,
# la que recomienda Shopify, aplicada a TODAS las tablas del conector que sirven
# para analizar el negocio, más la publicidad de cada plataforma a nivel de
# anuncio (Google Ads y Meta Ads con el paquete `ad_reporting` de Fivetran;
# TikTok Ads y Amazon Ads con modelos propios sobre sus informes diarios) y los
# informes de detalle para explorar. El objetivo es mostrar el valor con datos
# reales sin personalizar ninguna decisión. Si la marca sigue, la segunda fase
# (expediente en clients/<slug>/) personaliza, automatiza y da recurrencia.
#
# Las cinco son fuentes propias: una copia puede ser solo de Shopify, solo de
# anuncios o de cualquier combinación, y basta con una. El nombre del perfil se
# mantiene (`shopify-free-v1`) porque Core lo lleva en cada copia.
#
# El runner lo ejecuta en MODO PERFIL: cliente, cuenta, conexión y parámetros
# los aporta el runtime por variables de entorno (CHALS_CLIENTE, CHALS_PARAMS_JSON,
# CHALS_CONEXION), porque cambian con cada cuenta que conecta sus fuentes. Aquí
# solo vive lo que es igual para todas. Reglas R1, R3, R3b, R8 y R28.
#
# CHALS_PARAMS_JSON.raw (el dataset de Shopify) es opcional: sin él no hay
# tienda, las 20 tablas de Shopify se omiten (`omitida_sin_origen`) y se publica
# lo que haya de anuncios. Tiene que venir al menos `raw` u `origenes`.
# CHALS_CONEXION es la conexión de Shopify si su carga está en pausa verificada
# y, si no, la de la primera fuente de anuncios lista por orden alfabético de
# servicio; la frescura se comprueba contra ella.
#
# Un fallo de una plataforma de anuncios retiene solo esa plataforma (3.3.0): si
# la parte de `anuncios` que es suya no pasa los controles, el runner reconstruye
# el grupo Publicidad sin ella, conservando sus filas de la última publicación,
# y deja una fila `origen_retenido` (tabla = el servicio). Si solo falla su
# grupo de exploración, se retiene ese grupo, como en la 3.2.1.
perfil: shopify-free-v1
