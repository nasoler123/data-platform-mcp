# Shopify · Revisión semanal

Manual para el agente. Frase de arranque: **«Prepara mi dashboard de Shopify»**.

Lee [ejecución personalizada](references/ejecucion.md) al iniciar. Descubre contexto
y herramientas, presenta una propuesta concreta y **espera la validación o el
feedback del cliente antes de construir la primera entrega**. En actualizaciones
reutiliza lo aprobado y conserva las partes no afectadas.

Lee [objetivos y recomendaciones](references/objetivos.md) antes de proponer: acuerda
qué decisión o resultado debe resolver el encargo y cómo comprobarlo. La entrega
debe responder a cada objetivo con evidencia, recomendaciones explícitas y seguimiento.

Entregables predeterminados: `Dashboard.html`, `Revision.md`, `Resultados.json`, `contexto.json`. Conserva también los
archivos y acciones condicionales definidos en el método. Solo cambia el formato
si el cliente lo solicita o lo acuerda al validar la propuesta.

Usa el [método del workflow](references/metodo.md) para escoger el recorrido del
encargo; carga sus referencias cuando sean necesarias. La [guía del dashboard](references/dashboard.md)
define capacidades y verificaciones, no una plantilla. Genera el HTML y el código
necesarios para este cliente. No se distribuye ni se exige un motor local.

Chals aporta las tools y definiciones vigentes. Conserva sus permisos y reglas de
medición. Sigue [ejecución](references/ejecucion.md) para recuperar datos, comprobar
filtros/cifras y mantener memoria. Aprobar el diseño no autoriza actuaciones externas.
